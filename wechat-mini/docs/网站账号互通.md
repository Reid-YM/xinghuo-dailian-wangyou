# 网站账号互通

「我的」页已加入星火网站账号状态和登录码确认入口。网站登录页生成八位短期码后，在小程序输入；网站原浏览器核对微信识别码尾号并二次确认，才会建立网站会话。网站已有邮箱账号可从账号设置中发起同样的关联流程。

小程序用 `wx.login` 的一次性 code 向网站证明微信身份。网站需要在服务端配置小程序 AppID 与 AppSecret，并部署新增接口；小程序后台需要把 `https://wydlgf.cn` 加入 `request` 合法域名。不得将 AppSecret 放入小程序源码。未配置时，小程序进度记录和原有微信云同步继续工作，网站关联入口显示不可用。

网站资料和迷彩进度目前分别保存在网站账号系统与微信云开发中；关联同一身份后，「我的」可显示网站昵称和星火账号号。跨端订单详情和迷彩进度合并仍需后续单独设计数据权限与冲突规则，本次不擅自合并历史数据。

## 登录码入口始终可用（2026-10-13 修复）

网站浏览器会话默认 8 小时（勾「记住这台设备，30 天内免登录」才是 30 天），过期后网站会回到登录页。

此前「我的」页只在**未关联**时显示「登录网站 / 关联账号」按钮，而账号一旦关联成功，这个按钮就消失了 —— 已关联的账号再也找不到输入登录码的地方，于是网站一直停在登录页。

现在按钮在已关联时也保留（文案变为「在浏览器登录网站（输入登录码）」）：输入码只是把浏览器登录到**已存在**的关联账号上，不会重复建号，也不会改动关联关系。
## 退出小程序登录后仍可登录网站（2026-10-13 修复）

「退出小程序登录」只清微信云身份（进度同步用），与网站账号是两条独立通道：
网站登录/关联靠 `wx.login` 一次性 code，退出云登录不影响它。

两处曾经的坑：

1. 输登录码的入口只在「未关联」时显示，已关联的账号找不到入口 —— 已改为常驻（见上一节）。
2. 网站确认页要求核对「微信识别码尾号」，而这个尾号取自云状态的 openid，
   退出登录会被一起清掉，小程序这时显示为空，用户没法核对。
   现在把 6 位尾号单独存在 `xh_openid_tail_v1`，退出登录不清（它不是登录凭据）。
