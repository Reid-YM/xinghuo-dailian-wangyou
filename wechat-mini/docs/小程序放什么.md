# 小程序里能放什么、不能放什么

这份文档回答一个具体问题：**「能不能把星火网站直接转成小程序？」**

结论：**不能直转，但可以做「同一个网站的第二块屏」**。下面是有依据的说明。

---

## 一、为什么不能直接"转"

### 1. 不能把网站套进小程序（web-view 限制）

微信官方文档 · web-view 组件：

> 「承载网页的容器。会自动铺满整个小程序页面，**个人类型的小程序暂不支持使用**。」

而且要用 web-view，还得：

1. 在小程序后台配置**业务域名**，并且把微信的校验文件放到网站根目录；
2. 网站必须 HTTPS。

即便都满足，**把整站塞进 web-view 也会被判「小程序仅承载网页内容」而驳回**——
小程序审核要求你提供的是原生体验，不是一个网页壳。

### 2. 更不能放的是"代练"本身（这条是硬红线）

微信官方文档 · 服务类目与资质，类目「**电子娱乐服务**」：

> 资质：《营业执照》（经营范围含"互联网游戏服务"或"动漫游戏开发"相关）
> 说明：适用于提供电子娱乐相关服务。
> **注：不得提供代练（代打）或违法（如色情交易等）相关服务。**

**微信明文规定不得提供代练（代打）服务。** 所以：

| 网站上的东西 | 能不能进小程序 | 原因 |
| --- | --- | --- |
| 服务列表、报价（`/api/services`：武器升级 20–60 元 …） | ❌ 绝对不能 | 直接命中"提供代练服务" |
| 下单页 `/order`、报价页 `/quote` | ❌ 绝对不能 | 同上 |
| 支付、收款 | ❌ 绝对不能 | 虚拟服务交易另有资质要求 |
| 页面上写"代练/代打/代做"字样 | ❌ 不能 | 同上 |
| 迷彩追踪工具（`/api/tool-station`） | ✅ 可以 | 纯查询工具，和代练无关 |
| 攻略内容 | ✅ **已完成**（攻略 tab） | 内容资讯 |
| 业务记录查询 `/records/{单号}` | ✅ 可以 | 用户查自己的单 |
| 客服咨询入口 | ✅ 可以 | 平台自带能力 |

## 二、所以正确的做法是：小程序做前端，成交在客服里

```text
        ┌──────────────── 微信小程序（合规区）─────────────────┐
        │  迷彩追踪工具（主界面）      攻略 / 业务记录查询       │
        │              ↓ 用户卡住了 → 客服会话                  │
        └───────────────────────┬─────────────────────────────┘
                                │ 私聊（这里不受小程序页面审核约束）
                                ▼
                   报价 → 引导到星火网站 / 闲鱼 / 淘宝成交
```

**这条链路是合规的**，而且转化不比在小程序里直接卖差：
用户是"打不出来"才找你的，这时候他已经在跟你私聊了，报价和成交在哪都能完成。

## 三点五、攻略源内容处理记录

2026-10-12 已在星火网站后台修订 7 篇攻略的标题、摘要、正文或 FAQ。修改前原文见 `docs/攻略原文备份-2026-10-12.json`；当前 `tools/probe-filter.js` 显示 11 篇全部收录、过滤 0 段。

`miniprogram/utils/guides.js` 和 `config/business.js` 的 `CONTENT_FILTER` 仍作为回归保护：标题、摘要、标签命中会隐藏整篇，正文和 FAQ 命中会按段过滤。每次网站新增或修改攻略后，运行 `tools/compliance.js` 并人工抽读页面。

## 四、下一步能加的（都在合规范围内）

1. **业务记录查询**：网站已有 `/api/records/{businessNo}`，
   小程序里加个输入框，用户输单号就能看进度——代练客户最高频的动作，完全合规。
2. **攻略**：网站 `/guides` 是 Thymeleaf 服务端渲染的，没有 JSON 接口。
   要在小程序里做，需要给后端加一个 `/api/guides` 列表 + 详情接口（我可以写）。
3. **迷彩图鉴**：`/api/tool-station` 里每档迷彩都有预览图，可以单独做个图鉴页，方便做内容传播。

**不做**：服务列表、报价、下单、支付——这几项一旦进小程序就是自找驳回。
