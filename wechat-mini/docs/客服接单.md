# 客服接单说明

这份文档讲三件事：**客服入口在哪、用户找过来时你能看到什么、什么话不能说**。

---

## 一、用户会在哪三个位置点客服

| 位置 | 页面 | 触发方式 | 设计意图 |
| --- | --- | --- | --- |
| 悬浮按钮（右下角常驻） | 迷彩进度 | 任何位置都能点到 | 不打断勾选，但一直在他眼前 |
| 进度卡下方的卡片 | 迷彩进度 | 看完总进度就看到 | 抓到「我卡住了」的那一下 |
| 「我的」页大按钮 | 我的 | 登录/同步之后 | 最信任的时刻 |

三处都是 `open-type="contact"`，点开就是微信客服会话，**不需要跳外链、不需要填表单、不需要等审核**。

## 二、用户找过来时，你会看到什么

代码会把上下文塞进客服会话（`session-from`），格式是：

```text
工具咨询|模式:Multiplayer|进度:42%
```

也就是说，用户还没说话，你就已经知道：

1. 他是在 MP / Warzone / DMZ 哪一栏卡着的；
2. 他的总进度到多少了。

另外「我的」页有个 **「复制进度发给客服」** 按钮，用户一键复制：

```text
MW4 迷彩进度：85/202（42%）｜MP 80/66，WZ 5/66，DMZ 0/66｜Event 1/4
```

用户粘过来，你就直接知道差哪些，不用来回问。

> 云端数据库里还能看到每个用户的 `pct` 和 `updatedAt`：
> **进度高但很久没动 = 卡住了 = 最值得主动触达的人**。

## 三、接单话术模板（可直接用）

**用户刚开口（先给价值，别急着报价）**

> 你好，看到你在追 MP 的 Mercurial Drift。这个的第三段要 10 次三连杀，很多人卡这儿。
> 你是想自己打，还是让我们帮你收尾？

**用户说打不出来**

> 可以。你把「复制进度发给客服」的内容发我，我看下具体差哪几把，然后给你报个准数——
> 要多久、多少钱一次说清，不会先报价再改。

**用户问价格**

> 单把三段收尾和整套包干是两套价。你把缺的武器发我，我按缺的数量给报价，
> 超过 5 把给你算打包价。（具体价格按你的实际定价改）

**用户犹豫**

> 不着急。工具你继续用，进度我一分不少给你留着。哪天想收尾了再找我，价格不变。

## 四、合规红线（这四条别踩）

1. **小程序页面上不要出现**：代练、代打、代做、代肝、售卖、下单、微信号、QQ号、支付宝、外链网址。
   → 这些字眼全部只出现在**客服会话里**。用户已经在会话里跟你私聊了，不需要写在页面上。
2. **小程序中的客服入口统一使用工具咨询文案**，具体业务信息在客服会话中按实际需求说明。
3. **不要在小程序里直接收款**。微信小程序做虚拟服务交易需要资质，绕开支付走个人转账也违反规则。
   客服会话里引导到你已有的渠道（星火网站 / 闲鱼 / 淘宝）成交，是更稳的做法。
4. **用户数据只用来同步进度和接单**。后台的隐私保护指引里怎么写的，就必须怎么用，别拿去发广告。

## 五、想提升转化，下一步可以做

按性价比排序：

1. **客服欢迎语**：在后台配一条自动回复，比如「发一下你的进度截图，我看看差哪几把」——省掉第一轮寒暄。
2. **进度卡 80% 以上的用户**：数据库里筛 `pct > 80`，进度好久没动就是最精准的客户。
3. **高难度项单独成页**：Event 迷彩、榴弹发射器这类特别难打的，单独做个说明页，
   页面上放客服入口，转化率比首页高得多。
4. **接入星火主站**：把云函数里的存档转发一份到 `xinghuo-dailian-wangyou` 后端，
   在星火后台统一看用户、看订单、发优惠，不用在小程序后台和网站后台之间来回切。

## 附：转化版客服文案（**提审时不要用**，过审上线后再考虑）

你要的那句「迷彩代解锁 / 活动 / 周常 / DMZ」如果**直接写在小程序页面上，提审大概率被驳回** ——
微信类目文档原文：「（电子娱乐服务）**不得提供代练（代打）**」，
「代解锁」属于典型代练表述。所以代码里现在用的是**咨询口径**：

```js
// miniprogram/config/business.js
copy: {
  cardTitle: '有不懂的地方？',
  cardDesc: '迷彩解锁条件、活动、周常任务、DMZ 玩法，有不清楚的直接问客服。',
  buttonText: '联系客服'
}
```

**过审上线后**，如果你想换成转化版，把 `config/business.js` 里 `SERVICE.copy` 整块替换为：

```js
copy: {
  floatText: '找代做',
  cardTitle: '迷彩代解锁 · 活动 · 周常 · DMZ',
  cardDesc: '迷彩代解锁、活动、周常任务、DMZ，都可以交给我们，联系客服了解。',
  buttonText: '找代做',
  sessionPrefix: '代做咨询'
}
```

改完重新上传一版即可（**这会带来审核风险：若被复查可能被要求整改或下架**，请自行权衡）。
真正的转化本来也不靠页面文案 —— 用户是在「打不出来」的时候点客服，会话里怎么说都没有限制。
