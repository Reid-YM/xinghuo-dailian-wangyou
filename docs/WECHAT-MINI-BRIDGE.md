# 网站与星火小程序账号互通

当前实际客户端源码为仓库 `wechat-mini/` 中以协作者“星火迷彩追踪器”1.0.13 源码包为基础的 1.0.14 候选版；原“星维网络”独立演示小程序已从交付源码中替换。网站登录码二维码仍使用 `xingwei-login:<8位码>` 协议。2026-10-14 用户已用预览码完成扫码、微信确认及原网页登录主链路；体验版/正式版发布和其他边界场景另行验收。

## 当前能力

- 网站邮箱账号可在「账号设置 → 账号安全」生成关联码，在小程序「我的」输入，再回到原浏览器核对微信识别码尾号并确认绑定。
- 未登录网站的用户可在登录页用同样的双端确认流程创建或进入星火账号。
- 小程序通过 `wx.login` 获取一次性 code；网站服务端使用小程序 AppID 与 AppSecret 向微信 `jscode2session` 校验身份。AppSecret 不进入小程序代码、浏览器或 Git。
- 网站与小程序的 `OpenID` 按应用分别保存。若将来取得同一微信开放平台下的 `UnionID`，已有网站应用扫码登录也会查找同一星火账号；冲突时拒绝自动合并。
- 网站业务记录仍按星火账号原有归属规则读取；小程序迷彩进度仍由微信云开发同步。此次互通没有把网站密码、订单明细或云数据库凭据复制到小程序。

## 启用前配置

1. 在微信小程序管理后台查看 AppID，并由管理员安全地取得 AppSecret。
2. 在网站生产环境的密钥管理中设置 `WECHAT_MINI_APP_ID`、`WECHAT_MINI_APP_SECRET`。不要把值写入仓库、PR、聊天消息或客户端文件。
3. 小程序后台将 `https://wydlgf.cn` 加入 `request` 合法域名。
4. 部署包含 `V59__wechat_mini_pairing.sql` 的网站版本，再发布包含「我的 → 登录网站」的同版本小程序。
5. 用未登录网站的新微信号、已有邮箱账号绑定、错误码、过期码、重复使用码和两台浏览器各测试一轮。确认浏览器必须二次点击，且识别码尾号一致。自动化回归覆盖无效、过期和重复码；真机记录仍需逐项补齐。

网站应用扫码登录另需微信开放平台审核通过的网站应用 AppID、AppSecret 和授权回调域；未开通时页面只展示小程序确认入口。启用它可设置现有的 `WECHAT_OPEN_APP_ID` 与 `WECHAT_OPEN_APP_SECRET`，并把网站应用与小程序绑定到同一个开放平台账号。`UnionID` 仅在微信满足下发条件时存在，不以相同微信号文字或小程序 `OpenID` 猜测跨应用身份。

## 安全与回滚

- 登录码为八位数字、五分钟有效；服务端只存哈希，并对发码、尝试、轮询限流。
- 浏览器另持有 HttpOnly 的高熵 Cookie；小程序输入登录码只提交待确认微信身份，不能直接绑定网站账号或领取浏览器会话。
- 原浏览器核对微信识别码尾号后点击确认，才会一次性消费码、关联身份、签发网站会话。
- `V59` 是加表迁移，旧版服务可继续运行。若回滚应用版本，保留新表即可；不要为了应用回滚而删除账号或身份数据。
- 预览版真实微信账号已完成一次正常登录主链路验证；新账号与已关联账号分别验证、异常码、跨设备及正式版发布尚待独立记录。现有邮箱登录不受影响。
