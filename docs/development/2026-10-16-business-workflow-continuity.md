## 本轮行为

| 场景 | 处理 |
| --- | --- |
| 负责人候选读取中或失败 | 保存和选择暂不可用，可关闭；失败可重新读取候选；每次打开都重新读取，旧请求不覆盖新窗口 |
| 已选择归属尚未保存 | 取消、关闭、Escape 需要确认，离页显示浏览器未保存保护 |
| 正在保存归属 | 当前页面只允许一个写请求；锁定关闭、取消和选择；拒绝刷新/切换产生竞争读取 |
| 归属已写入，列表刷新失败 | 明确显示“业务归属已保存，但列表刷新失败”，允许刷新核对，不伪报列表已加载 |
| 归属写入超时或连接中断 | 显示结果尚未确认，禁用本窗口继续提交，要求关闭并刷新业务列表核对 |
| 列表重新读取或切换 | 清空旧记录、按钮、计数与分页；过期成功/失败均不改新结果，最新请求管理加载状态 |
| 订单/询价字段及截图有未保存内容 | 输入、下拉变更与文件选择均进入离页保护；关闭确认放弃才重置 |
| 保存订单时已选截图但未上传 | 先确认清除未上传选择；取消保留字段与文件；上传成功更新版本并清除文件标记 |

权限、CSRF、询价 expectedStatus、订单/截图 version 与原业务 API 保持。无新增支付、退款、外部写入、数据库迁移或生产配置修改。当前页面防重复不等同于跨员工同时改派的服务端乐观锁，本轮未改变该接口的并发协议。
