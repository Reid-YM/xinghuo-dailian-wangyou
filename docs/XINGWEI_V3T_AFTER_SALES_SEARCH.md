# V3T 售后问题记录检索与翻页

V3S 的后台售后页签只返回最近 100 条，浏览器搜索只能匹配这 100 条。V3T 在现有 `GET /api/admin/xingwei/business/orders/after-sales` 上增加可选参数 `q` 和 `page`，按服务器数据范围查询所有匹配记录，再按更新时间与订单 ID 倒序翻页，每页 50 条。返回 `totalCount`、`page`、`pageSize` 和 `hasNext`，原有无参数调用仍返回第一页。

搜索范围是业务编号、订单号和客户提交的说明；最多 80 字，页码为 0–1000。数据库查询先应用 `order:view` 对应的 ALL / DEPARTMENT / SELF 数据范围和售后标记，再计算总数并分页。客户端不保存完整记录集；切换页签后重新从第一页读取，搜索词变化也回到第一页。客户备注继续作为纯文本展示。

该阶段不新增数据库迁移，不改变订单、退款、支付写入或归属分配规则。验收关注中心与本人范围、较早记录搜索、翻页、空结果、长搜索参数和 HTML 字符串转义。回滚可使用上一版服务与静态资源；接口新增参数与返回字段对旧调用兼容。
