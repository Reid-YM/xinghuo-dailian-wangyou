# 独立工作区二级分类

基线：右侧独立工作区 PR #518 已由生产发布 #224（主线 `f1814784`）完成。用户要求再细分，本阶段在右侧增加二级分类；合并与生产部署分别记录。

| 工作区 | 二级分类 |
| --- | --- |
| 业务中台 | 询价与订单、服务与目录、内容与社区、会员与运营 |
| 组织与权限 | 中心与岗位、员工与账号、角色与权限 |
| 渠道与微信 | 渠道运营、微信与支付、前台展示 |
| 系统工具 | 站点配置、操作审计、发布与工具 |

共 13 个分类，保留原有 26 个模块，不复制或删除业务入口。组织中心/岗位、员工档案及权限表分别随其分类显示。

## 导航与权限

- 右侧分类导航仅展示当前分类及有可用内容的其他分类；计数是当前权限下可用的模块入口与资料表数量，不是业务记录总数。
- 从左侧工作区进入时，自动选择首个可用分类。权限未读取完成前不先选定并暴露未核验内容。
- 分类使用 `#business/catalog` 等地址，可分享、刷新及前进后退。原有 `#org-console`、`#org-positions`、`#org-employees`、`#org-roles` 继续定位到对应分类和资料。
- 明确进入无权限分类时显示无可用内容提示；不悄悄切换到其他分类。未知分类回到本工作区首个可用分类。
- 搜索继续跨工作区与分类查找模块，隐藏组织资料表；清除搜索回到原分类。搜索时标题恢复为工作区，普通分类则显示具体任务标题与说明。
- 仅有员工查看权限时，仍可看到服务端允许的中心和岗位资料；不因为 O01 模块需要 org:view 而误隐藏资料表。权限及数据范围仍由原后端执行。
- 分类链接保留键盘焦点和当前项语义，手机换行显示；普通切换从顶部开始，深层资料链接继续定位。

## 界面与所有者

Visual thesis：围绕单一运营任务显示内容，减少一个工作区内的杂项混排。
Signature device：右侧黄色分类链接与对应任务标题、资料表一致。
Aesthetic risk：默认只展示当前分类，其他内容通过明确标签进入。
Rejected generic choice：无新仪表指标、iframe、补丁样式层或业务数据源。
Density / motion：紧凑分类链接，沿用现有菜单和减少动效偏好，无新增动画。
Intentional tradeoff：保留原模块、资料表和编辑器，使用已有 JS 管理显示与地址，避免复制保存流程。
Responsive checks：桌面与手机分类、键盘进入、无横向溢出。
States checked：权限读取、完整管理员、仅订单/内容/员工权限、零权限分类、未知分类、搜索、清除、刷新、历史和组织锚点。
Functional validation：本地实际浏览器、Maven 构建、原有组织对话框/版本侧栏/运行健康回归与 PR/主线双浏览器 CI 的结果单独归档。

HTML 负责分组结构，`admin-xingwei.js` 负责分类导航及权限过滤，已有 CSS 负责展示。分类标签、任务说明均为中文。没有数据库、服务端接口、角色权限、生产配置或正式前端默认切换；正式前端保持旧版。测试使用虚构账号与模拟接口，不执行生产写入，不替代真实员工验收。

## 细节搜索与中文补查

本轮扩展搜索为功能、字段、操作入口索引，支持空格组合关键词、按真实模块权限及全局数据范围过滤、精确名称优先。静态字段和操作使用真实 URL 锚点；异步站点配置按分区读取完成后滚动、聚焦并高亮字段。订单、员工、目录记录的编辑字段只导航到对应工作台或资料表，明确提示先选记录，不自动选记录、打开编辑或执行写入。搜索定位功能元数据，实际业务记录仍由对应列表按数据权限查询。

索引由 `scripts/generate-admin-search-index.py` 从模板、共享表单和既有站点字段定义生成；CI 的 `--check` 同时核对生成物和静态目标锚点，避免菜单存在但跳转无效。共享表单为缺少标识的静态控件补充稳定锚点，保留原字段名、请求值和写入接口。

中文补查覆盖主工作台及原生子页的固定文案、权限模式、服务标识与发布检查、分类状态、请求失败提示，以及审计类型、业务对象和受保护的枚举变更摘要。审计筛选的请求值继续使用原动作代码，中文仅影响显示，原代码可从提示中核对；账号名、业务标识、环境变量名、用户内容及未知历史代码保持可追溯。

视觉延续现有深色工作台，桌面搜索结果双列、手机单列，结果区限制高度并支持键盘访问，保留当前分类和清除搜索后的返回路径。加载失败会明确提示降级到模块筛选；未授权、空结果与不可用分类都有独立空态。验收增加了实际点击搜索结果到站点字段、异步渲染后焦点/可见性、受限员工搜索、员工档案定位及审计中文与原协议值并存的浏览器验证。

最终本地验证：Maven clean package 646 项（0 失败/错误、160 项浏览器跳过），相关实际 Chromium 共 17 项通过；索引检查 409 条与静态目标通过。PR/主线 CI 及生产记录保存在交付目录，发布前不以本地结果代替发布结果。
