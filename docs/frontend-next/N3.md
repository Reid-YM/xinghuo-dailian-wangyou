# Frontend Next N3：真实询价提交

## 目标

在继续保留旧 `/quote` 的前提下，让 `/next/quote` 使用现有生产询价接口完成真实提交。

## 接入能力

- 复用现有 `POST /api/quote`，不新增第二套询价后端。
- 每次提交携带 `Idempotency-Key`，失败重试保持同一 key，避免重复创建询价。
- 提交中锁定按钮，阻止重复点击。
- 失败后保留用户当前输入并恢复按钮，允许直接重试。
- 成功后展示现有 `businessNo`。
- 新版表单补充游戏平台、期望时间、联系方式类型与隐私同意。
- UTM / referrer 继续以现有 PublicQuoteRequest 字段写入。

## 安全边界

- 不收集、不上传账号密码、验证码或令牌。
- N3 暂不接任务截图上传；截图能力继续由旧询价页承接，后续单独验收。
- 动态提示全部使用 `textContent` / DOM API，不把接口返回内容写入 `innerHTML`。
- 不修改旧 `/quote`，新版出问题可直接回退旧入口。
- 仍复用服务端现有校验、网页询价开关、幂等处理和账号联系方式补齐能力。

## 验收重点

1. 正常提交只生成一条询价。
2. 双击按钮不会产生重复请求。
3. 网络中断 / 5xx 后再次点击使用原幂等 key。
4. 未勾选服务规则与隐私说明不能提交。
5. 服务端关闭网页询价时显示明确错误，不伪造成功。
6. 成功后显示业务编号，旧询价页与旧查询路径仍正常。
