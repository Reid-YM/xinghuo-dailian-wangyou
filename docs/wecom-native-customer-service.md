# 企业微信原生在线客服接入

## 目标

官网提供星火品牌化的“在线客服”入口；用户点击咨询类型后，由服务端跳转到企业微信官方“微信客服”会话。聊天本身不经过本站自建 IM，客服继续在企业微信原生客户端/工作台接待。

## 当前实现

- 全站公共页脚增加“在线客服”浮动入口。
- 支持游戏咨询、订单咨询、售后处理、商务合作四类入口。
- `/customer-service/start` 只允许跳转到 `https://work.weixin.qq.com/kfid/...` 官方链接。
- 服务端日志只记录咨询类型和来源页面路径，不记录来源查询参数、Cookie、IP。
- 未启用、未配置或配置非法时，自动回退 `/contact?customerService=unavailable`。
- 不在浏览器中暴露企业微信 Secret，也不自建消息转发协议。

## 生产环境配置

从企业微信管理后台取得对应微信客服帐号的“微信外网页接入”官方客服链接后，在生产环境设置：

```bash
WECOM_KF_ENABLED=true
WECOM_KF_URL=https://work.weixin.qq.com/kfid/你的官方客服标识
```

应用重启后，访问任意使用公共页脚的页面，点击“在线客服”并选择咨询类型即可验证。

## 验收清单

1. PC 与手机端都能看到客服入口，且不遮挡主导航/手机底部 Dock。
2. 四类咨询均先请求本站 `/customer-service/start`，随后 302 到已配置的企业微信官方链接。
3. 客户可在官方客服会话内发送企业微信支持的文本、图片、文件等消息。
4. 企业侧仍按当前原生微信客服接待方式处理，不需要进入本站后台回复。
5. 将 `WECOM_KF_ENABLED=false` 后，客服入口请求不再跳向企业微信，而是回退到本站联系页。

## 关于后续 API / CRM 同步

当前版本**不启用微信客服 API 接管模式**。原因是原生接待优先：企业微信对开启 API 后的客服帐号、会话分配和消息收发有单独的管理规则，不能为了做聊天归档就直接在生产环境开启。

后续若需要“会话归档、订单关联、AI 摘要、客服质检”，应单独开发并验收微信客服 API 模式，包括回调验签/解密、`sync_msg` 游标同步、消息幂等、媒体文件下载、会话与业务编号映射、权限与 Secret 管理，并在确认不会破坏现有人工接待流程后再切换。
