# Frontend Next N2：只读数据接入

## 状态

N1 四页并行预览继续保留，N2 开始复用现有公开接口，不复制新的后端服务。

- `GET /api/catalog`：读取游戏、分类、平台与游戏-平台关系。
- `GET /api/services`：读取公开服务列表。
- 服务大厅接口成功时用真实公开数据渲染；失败时保留 V1 静态卡片回退。
- 新版询价页的游戏、分类、服务选项开始跟随只读数据联动。
- 当前仍不调用 `POST /api/quote`，不会写生产询价或订单数据。
- 个人中心仍为演示记录，N4 再接账号会话和用户只读数据。

## 隔离方式

旧 `/`、`/services`、`/quote`、`/account` 不变。新前端仍只通过 `/next`、`/next/services`、`/next/quote`、`/next/account` 访问。

`FrontendNextPreviewController` 在返回原 V1 页面时只追加同源 `/next/n2.js` 运行时；原静态 `index.html` 保持为可回退基线。N2 运行时失败不会阻断 V1 静态页面。

## 安全边界

- N2 运行时只发起同源 GET 请求。
- 接口返回文案使用 DOM `textContent` 创建，不直接写入 `innerHTML`。
- 封面仅接受站内相对地址或 `https://` 地址。
- 不调用后台管理 API，不修改服务、分类、询价、订单和账号状态。

## 验证

- Java 21 / Maven Build：通过。
- Chromium + WebKit UI Regression：通过。
- 新增 Frontend Next N2 contract test，固定只读接口、静态回退与不写生产数据的边界。
