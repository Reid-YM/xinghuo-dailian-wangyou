# 星火网游 · Logo / 宣传图 / 头像（非星星方向）

本轮按"换个思路、不一定是星星"的要求，做了 **一套全新的非星星 Logo 方向（Style D）**，并基于它产出 **宣传图 4 张 + 头像 8 款**。

> 重要前提：当前会话**没有可用的内置图像生成工具**。因此宣传图与头像全部用 **矢量 / HTML 精确构建后渲染成 PNG**——不是 AI 生成的位图。好处是尺寸精确、可无限缩放、文字不会糊、可复现。

## 1. Logo · Style D「四级等级条」

![等级条标记](explorations/11-style-d.png)

**核心概念**：四根圆头竖条从低到高排列，代表"从当前进度到目标等级"；四根条用**同一金色的四级明度**（`#D89A00 → #F0B000 → #FFC928 → #FFD24A`）递增，越高的等级越亮——把"上分"这件事直接画成一条上升的金色梯度。

**为什么是它**

- **业务最贴**：星火网游卖的就是"把账号从 A 推到 B"，等级条是这个业务最直白的图形。
- **不是星星**：完全脱离"火花/星星"的常见套路。
- **尺寸最稳**：16px 下四根条仍是四根条，不会糊。
- **能成系统**：四根条可以映射四个服务档位 / 四个流程步骤 / 四类业务，天然可扩展。
- **与现有品牌不冲突**：四级金色全部来自站点现有金色链。

**文件**

```
styles/
├── style-d-icon.svg          标记 · 四级金色（深底用）
├── style-d-icon-mono.svg     标记 · 单色（浅底 / 印刷 / 极小尺寸）
├── style-d-lockup.svg        横向组合（标记 + XINGHUO）
└── png/                      512 / 256 / 128 / 64 / 32 / 16 与组合 2048
```

**最小尺寸**：标记 ≥ 16px（屏幕）/ ≥ 4mm（印刷）；横向组合 ≥ 120px。

**颜色**

| 名称 | HEX | 用途 |
|---|---|---|
| Tier 01 | `#D89A00` | 最低一档 |
| Tier 02 | `#F0B000` | 第二档 |
| Tier 03 | `#FFC928` | 第三档 |
| Tier 04 | `#FFD24A` | 最高一档 |
| 墨黑 | `#0A0C0F` | 背景 / 单色 |

单色版本只用一个颜色（墨黑 / 纯白 / 星火金 `#F5B700`）。

## 2. 宣传图 · 4 个规格

全部为**精确像素输出**，可直接投放。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `promo/png/promo-square-1080.png` | 1080×1080 | 微信朋友圈 / 社群 / 淘宝主图 / 通用方图 |
| `promo/png/promo-story-1080x1920.png` | 1080×1920 | 抖音 / 视频号 / 小红书 story 竖版 |
| `promo/png/promo-banner-1920x1080.png` | 1920×1080 | 网站 hero / 直播间贴片 / 视频封面 |
| `promo/png/promo-og-1200x630.png` | 1200×630 | 链接分享卡（可直接替换站点 `og.png`） |

**画面系统**

- 底色统一墨黑 `#0A0C0F`，唯一强调色是金色链；
- 左文右图（或上文下图）的固定骨架：`XINGHUO GAMING` 微标签 → 金色细线 → 大标题 → 副标题 → 三个卖点胶囊 → CTA；
- 等级条作为画面唯一的图形元素，方图里放大并出血到右下角当"图形锚点"。

**文案（已按合规口径写）**

主标题「游戏任务代练」· 副标题「按进度报价 · 提交拿业务编号 · 进度随时可查」· 卖点「可靠手打 / 纯绿服务 / 一号到底」· CTA「提前询价 · wydlgf.cn」

未使用：外挂、脚本、百分百安全、永久不封、全网第一等表述；未编造任何数字或业绩。

**改文案**：直接编辑 `promo/index.html` 里的文字，再重新渲染即可（命令见 §4）。

## 3. 头像 · 8 款

每个都是 512×512（另附 128×128 上传版），图形控制在中心安全圆内，**圆形裁切不会切到内容**。

| 文件 | 底色 / 图形 | 适用平台 |
|---|---|---|
| `avatar-01-dark-gold` | 墨黑底 + 金色等级条 | 主头像 / 官网 / 客服主账号 |
| `avatar-02-gold-ink` | 金底 + 墨色等级条 | 需要高识别度的广告位 |
| `avatar-03-xmark` | 墨黑底 + 金色 X | 备用（字母向） |
| `avatar-04-support` | 墨黑底 + 等级条 + 「客服」 | 客服个人号 / 售后号 |
| `avatar-05-taobao` | 淘宝橙 + 白条 | 淘宝店铺头像 |
| `avatar-06-xianyu` | 闲鱼黄 + 墨条 | 闲鱼头像 |
| `avatar-07-wechat` | 微信绿 + 白条 | 微信 / 企业微信 / 公众号 |
| `avatar-08-char` | 墨黑底 + 金色「火」 | 内容号 / 人设号 / 备选主头像 |

**平台头像注意**：淘宝 / 闲鱼 / 微信都会做圆形或圆角裁切，且部分平台会缩到 40–64px 展示，因此图形占比控制在 55–60%，不要塞小字（除 `avatar-04` 的「客服」二字，它位于中轴线上，可安全裁切）。

## 4. 重新生成（可选）

三个页面都是自包含 HTML（内联 SVG，无外部依赖），改完直接重新截图：

```bash
# 宣传图（4 个规格，精确像素）
node tools/shot-elements.mjs promo/index.html   promo/png   2000 5600 1
# 头像（512）
node tools/shot-elements.mjs avatars/index.html avatars/png512 1700 1200 1
# 头像（128 上传版）
node tools/export-avatars.mjs
# 标记位图
node tools/render.mjs styles/style-d-icon.svg styles/png/style-d-icon-512.png 512 none
```

## 5. 诚实说明

- 宣传图与头像是**矢量构建的成品**，不是 AI 生成图；如需照片级 / 场景级素材（真人代言、游戏实拍、3D 场景），需要接入图像生成工具或人工拍摄。
- 头像里的「火」字用的是系统字体渲染（已转成 PNG）；若要 SVG 母版，需要先转曲。
- `style-d-lockup.svg` 的 `XINGHUO` 仍为描边构建，交付印刷前建议在矢量编辑器执行一次 **轮廓化 + 联集**（与 README §7 的说明一致）。
