## 1. 先淘汰的一批一句话点子

写下来但很快否掉的（说明探索范围，不进入制作）：

1. 一团写实火焰：太直白，且是品类陈词滥调。
2. 字母 X + 闪电：闪电被代练行业用烂。
3. 盾牌里放 X：电竞队徽风。
4. 游戏手柄轮廓里藏星：太具象，缩小即糊。
5. 五角星 + 环：像军事 / 评级章，与"服务"气质不符。
6. 像素画笔：绑定"复古游戏"过深。
7. 火箭 / 上升箭头：像增长类 SaaS，不像游戏服务。
8. 龙 / 狼剪影：与"正规、服务"相反。
9. 纯字母堆叠 XHG：读不出含义，记忆点低。
10. 无穷符号 + 火花：寓意牵强。

## 2. 第一轮：5 个方向

### 方向 1 · 星火符 Spark Glyph

**设计名称**：星火符 Spark Glyph

**核心概念**：用一枚"四面火花"代表星火；四点落在对角线上，连起来正好是字母 X。

**图形结构**：256 网格；四个对角顶点 + 四个轴向凹点；四条边向内凹（曲线控制点内收），形成"发光"而非"锋利"的轮廓。

**为什么适合**：直接对应品牌名"星火"；对角结构暗合首字母 X；凹边向内收束＝能量汇聚，符合"点燃 / 成长"；不绑定任何游戏。

**优点**：极简、纯填充路径、不依赖渐变、黑白均成立；16px 可辨；易做辅助图形与动效。

**潜在问题**：四面火花是较常见的形（Sparkle 类）；需要靠具体凹度、比例与组合来建立识别。

**网站应用效果**：页头符号位直接可用，与现有金色链无缝衔接。

**小尺寸效果**：优。实心块面在 16px 仍是一个清晰的花火轮廓。

**是否容易形成品牌资产**：高。可独立成为 APP 图标 / 头像 / favicon，长期可脱离文字。

**综合评分**：**9.05**

### 方向 2 · 火核组合标 Flame Core Combination

**设计名称**：火核组合标（符号 + XINGHUO + 中文名）

**核心概念**：把"星火符"与自绘几何标准字锁成一个横向组合，中文名作为第二行。

**图形结构**：左符号（高 ≈ 1.5×字高）+ 右标准字；符号垂直居中于字高带；中文名另起一行。

**为什么适合**：新品牌需要"先读名字"；组合标既给识别符号又保证名字可见；最适合网站页头与名片。

**优点**：兼顾符号与名称；多场景可用；主次分明。

**潜在问题**：横向比例偏宽（约 4.8:1），很窄的位置会缩得很小；中文行依赖字体。

**网站应用效果**：页头、分享图、名片、报价单最合适。

**小尺寸效果**：中。窄栏中需要退化为符号版。

**是否容易形成品牌资产**：高。这是品牌最常用的"标准形态"。

**综合评分**：**8.55**

### 方向 3 · XH 合体 XH Monogram

**设计名称**：XH 合体字标

**核心概念**：把品牌首字母 X 与 H 放进同一块方形底板，X 的右臂与 H 的左竖共用节奏。

**图形结构**：圆角方形（rx ≈ 22%）+ 反白 XH；X 用方切端点与 45° 缺口；H 为两竖一横。

**为什么适合**：首字母直接可读，APP 图标感强；方形底板在各类平台都稳定。

**优点**：识别直接；适合做应用图标 / 网站图标；黑白反转都成立。

**潜在问题**：字母标含义偏薄，需要长期曝光；16px 下 XH 两个字母会糊，需要专用小尺寸版。

**网站应用效果**：适合做图标位；页头若放 XH 会与中文站名信息重复。

**小尺寸效果**：差。两个字母在 16px 会粘连，必须另做简化版。

**是否容易形成品牌资产**：中高。是很好的"图标备选"，但不足以单独承担品牌。

**综合评分**：**8.20**

### 方向 4 · 星火网游 定制字标

**设计名称**：星火网游 中文定制字标

**核心概念**：直接对"星火网游"做字处理，把"火"的能量感与整体字重统一。

**图形结构**：四个汉字 + 下方小字 XINGHUO GAMING（`concepts/d4-wordmark-zh.svg` 为**探索稿**，用系统字体排布示意）。

**为什么适合**：中文品牌最直接的传播方式，不需要"学习"符号。

**优点**：一眼读懂；横向排版整齐；适合信任类文案。

**潜在问题**：现成中文字体的字标没有独占性，谁都能打出来；中文字形转曲成本高；小尺寸笔画易并糊。

**网站应用效果**：适合正文 / 页脚 / 文档题头，不适合做页头图标。

**小尺寸效果**：中。四字并排后每字很小。

**是否容易形成品牌资产**：中。独占性弱，除非重绘字形。

**综合评分**：**7.35**

### 方向 5 · 星链 Spark Chain

**设计名称**：星链（节点火花）

**核心概念**：四个节点用对角连线穿过中心的火花核，表达"平台连接玩家与需求"。

**图形结构**：四角圆点 + 两条对角连线 + 中心菱形核。

**为什么适合**：直接对应"网游 / 平台 / 连接 / 一对一服务"；几何感强、偏科技。

**优点**：语义丰富；对称稳定；适合讲"平台"故事的场景。

**潜在问题**：元素偏多，缩小后节点与线会糊；中心核与连线交点容易显脏；辨识度靠细节而非大形。

**网站应用效果**：适合做大图 / 辅助图形，不适合页头小图标。

**小尺寸效果**：差。16–24px 基本糊成一团。

**是否容易形成品牌资产**：中。可作为辅助图形资产，难以成为主标。

**综合评分**：**6.95**

## 4. 第二阶段：TOP 3 深化

**星火符**

- 凹度迭代 3 轮：直边 → 轻微内凹 → 明显内凹。直边版读起来像忍者镖，明显内凹版才读成"发光的花火"，最终采用第 3 档。
- 收紧 viewBox（原始四周留白约 20%，收紧到各 12/256），小尺寸可见度明显提升。
- 黑白测试：纯色块面无依赖，黑白都成立。
- 深浅底测试：金色符号在 `#0B0D10` 上对比充足；浅底改用单色黑版本。
- 小尺寸：16px 仍是一个清晰的花火块面（见 `explorations/`）。
- 组合：横版（4.8:1）、竖版（1.9:1）、仅图标三种，均已锁定间距与相对大小。

**火核组合标**

- 标准字重从 22 降到 20（字高 100），更接近"专业 / 服务"而非"重电竞"。
- 符号高度定为字高的 1.5 倍，符号垂直居中于字高带。
- 修掉 `N` 斜边斜接产生的尖刺（改圆角接头），重画 `G` 的开口弧。
- 反白版本笔画由 20 减细到 19（约 −5%），抵消白字在深底上的视觉膨胀。

**XH 合体**

- 重排内边距：字母组在底板内上下左右各留 40 单位，不再贴边或被圆角切到。
- 缩小 X 与 H 的字宽差，两者视觉体量拉平。

## 5. 定稿

### 主方案：星火符 Spark Glyph

理由（按权重排序，不是"看着酷"）：

1. **长期品牌价值**：符号可脱离文字独立存在，先做识别、再做资产。
2. **辨识度来自大形**：四点对角 + 内凹边，缩小后靠大轮廓就能认出，不靠细节。
3. **扩展能力**：一枚纯填充路径，可衍生图标、favicon、头像、加载动画、辅助图形、角标等。
4. **商业可用性**：深浅底 / 单色 / 印刷 / 刺绣 / 切割全部成立，16px 起可用。
5. **与现有网站零冲突**：颜色沿用现有金色链，页头只换一个符号位。

主要表达形态采用 **横向组合标（符号 + XINGHUO）**，另有堆叠组合与仅图标版本。

### 备用方案：XH 合体字标

当需要"纯图标 / 方形容器"且希望露出品牌首字母时启用（例如应用商店图标、方形广告位）。代价是 16px 下需要另做简化版。

## 6. 还需要进一步优化的地方

1. **标准字轮廓化**：把描边路径转成纯填充路径（矢量编辑器 Outline Stroke + Unite），用于印刷 / 刺绣 / 切割。
2. **中文标准字**：目前沿用站点字体，未做字形。若要做纯字形版本，需选定可商用中文字体并授权转曲。
3. **16px 专用小尺寸版**：可再做一个 optical size 版本（凹口更大、笔画更粗一档），让 favicon 在低分屏更稳。
4. **商标检索**：无法提供法律判断，需到商标数据库做近似检索 + 反向图片检索。
5. **分享图 / OG 图**：`og.png` 仍是旧图，应用新组合重做 1200×630。
6. **辅助图形与动效**：可由符号的"向内收束"延伸一套放射辅助图形；加载动画可做"火种点亮"效果。
7. **深浅底自动切换**：站点接入时可用 CSS `currentColor` + 一个符号组件，避免同时维护多份文件。
8. **反白打样**：反白版本已减细 5%，建议印刷打样后再确认是否需要进一步减细。

## 8. 第二轮：高级感重做（v2 · 折光火花）

### 8.1 为什么要重做

v1「星火符」解决了"是否成立"（简洁、可缩放、单色可用），但没有解决"是否高级"：

- 单色实心的四角火花是常见形（Sparkle 类），缺少一个只属于星火网游的**记忆点**；
- 平面单色在深色底上偏"图标感"，撑不起品牌展示、名片、发布会这类高价值场景；
- 标准字的端点处理不够统一（对角笔画在字高外斜切出头），近距离看是工艺瑕疵。

结论：保留 v1 的**轮廓与结构决策**（对角线四点、内凹边、单一闭合路径），在**表面与工艺**上升级。

### 8.2 第二轮候选（3 个方向 + 3 个折面处理）

结构候选：

1. **Prism Spark 棱面火花**：上下两块金色 + 中心菱形镂空。
   → 双色太含蓄、中心孔在缩小时会消失，像"半张图被压暗"。
2. **Shard Spark 碎片火花**：四枚锥形碎片 + 中心菱形核，间隙留白。
   → 记忆点最强、很像"X 推进器"，但间隙让它在 16px 偏散，且锐感偏高，与"可靠 / 服务"略有冲突。
3. **Aperture Spark 环火**：开口圆环 + 中心迷你火花。
   → 元素过多，环与火花的交点显脏，16px 直接糊。

折面处理（对 v1 轮廓做材质实验）：

1. **F1 棋盘折面**：四象限两色交替 → 折感成立，但两色差异小，偏向"压暗"。
2. **F2 四阶光扫**（最终采用）：四象限四级明度，右上最亮 → 折感清晰、像切割金属，缩小后自然合并为实心火花。
3. **F3 对角对折**：一条对角折线、两色 → 最克制优雅，但记忆点弱于 F2。

渲染对比见 `explorations/02-premium-candidates.png`。

### 8.3 最终选择：F2 折面 + v1 轮廓

**折光火花 Fold Light Spark**

- 保留 v1 的外轮廓（四点对角、内凹边、R 116 / 内凹 54）。
- 中心用水平轴 + 垂直轴切四个折面，填四级金色：`#FFD24A → #FFC928 → #F5B700 → #F0B000 → #D89A00`。
- 光从右上落下：**唯一光源、唯一色相**，因此是"折面"而不是"渐变"。
- 单色版本仍是 v1 那条闭合路径 → 两版天然同一轮廓，资产不会分叉。

选择理由（不是"看着酷"）：

1. **记忆点明确**：多数火花 Logo 是单色平面，四折面给出可描述的特征（"右上亮、左下暗的那枚火花"）。
2. **可缩可放**：168px 能看清四个面，16px 自动并成实心火花，不需要另做一套图形。
3. **可单色可多色**：折面版用于屏幕与展示，单色版覆盖印刷 / 刺绣 / 切割 / 极小尺寸。
4. **与现有站点不冲突**：四个折面全部落在站点现有金色链内。
5. **不依赖渐变**：纯平涂，转 CMYK 与丝印都不需要额外工艺。

### 8.4 工艺修正

- **标准字重新校准**：字高统一到 100，笔画 22 → 20 → **18**（反白 17），字重从"重电竞"回到"专业 / 服务"。
- **端点对齐**：`X` 的对角端点从"在字高外斜切出头"改为与字高对齐（端点内收 9 个单位），`N` 的斜边改为独立线段 + 圆角接头，消除斜接尖刺。
- **`G` 开口弧重画**：改用两段 150° 圆弧（`large-arc=0`），避免单段大弧在某些渲染器下选错弧向。
- **字号间距**：字距 22 → 26，配合更细的笔画，长条形组合更透气。
- **锁版宽度**：横向组合由 940 → 966，左右留白平衡到 24 / 24。

### 8.5 v2 仍未做的

- 标准字仍是描边构建，交付印刷前需轮廓化（见 `README.md` §7）。
- 中文标准字仍沿用站点字体，未做字形与转曲。
- 折面版转 CMYK 需实际对色确认四个金仍可区分。
