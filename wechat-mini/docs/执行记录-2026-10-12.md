### ✅ 账号互通 502 已定位并修复（PR #360）

**根因**：微信 `jscode2session` 带真实凭据请求时返回 **`Content-Type: text/plain`**，
而 `WeChatMiniBridgeService.exchange()` 用 `restClient...retrieve().body(JsonNode.class)` 解析，
Spring 的 Jackson 转换器只接受 `application/json`，抛 `no suitable HttpMessageConverter`
后被 `catch (RuntimeException)` 收敛成 `WECHAT_SERVICE_UNAVAILABLE(502)` ——
**与 code 真假无关，所以每次必 502**。

**定位证据**（服务器只读核对，未改生产）：

| 排查 | 结果 |
| --- | --- |
| `.env` 凭据 | ✅ 正确（同凭据 curl 得 `errcode 40029`，只是 code 是假的） |
| 服务器 → 微信 | ✅ 通 |
| JVM 出网与证书链 | ✅ 正常（同机 JDK HttpClient 返回 HTTP 200） |
| 响应头 | ⚠️ 真实凭据下为 `text/plain`（不存在的 appid 才是 `application/json`，先前据此误判） |

**修复**：PR [#360](https://github.com/Reid-YM/xinghuo-dailian-wangyou/pull/360)
（`fix/wechat-mini-text-plain`，1 个文件 +11 -2）：先取 `String` 再自行 `ObjectMapper` 解析；
catch 放宽为 `Exception` 以覆盖受检异常。`mvn -o clean compile` 通过，CI 待跑。

**合并并部署后**应用真实 `wx.login` code 复验：应返回 `{"linked":true/false,...}` 而非 502。
部署需负责人明确授权。
