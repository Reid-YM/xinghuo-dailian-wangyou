# 星火网游 Logo 资产包

**方案：星火符 Spark Glyph（主方案）+ XH 合体字标（备用方案）**

本目录是"星火网游"重新设计后的完整 Logo 资产与预览页。整体方向延续现有网站"黑 + 金"的视觉基调，把品牌名里的"星火"做成一个可独立使用的几何符号，而不是"一团火 + 文字"。

> 说明：本次只交付设计资产与预览页，**没有修改线上站点、没有替换现有 favicon、没有部署生产**。文末给出"网站替换位置清单"作为后续建议。

---

## 1. 创意说明

### 符号：星火符

由四个对角方向的"火花"组成，四条边向内凹，形成一枚简洁的四面火花：

- **对角四点＝星火**：四点落在对角线上，是"火花 / 星点"的直接识别；
- **对角结构＝字母 X**：四点连起来正好是品牌首字母 **X**，一形两义；
- **凹边＝能量向内收束**：区别于普通四角星（忍者镖 / 罗盘），凹边让形更"发光"而非"锋利"；
- **纯色可成立**：不依赖渐变，单色黑 / 单色白都成立。

### 标准字：XINGHUO

几何无衬线大写，笔画粗细统一（字高 20%），圆角接头；`G` 与 `O` 用同心圆弧，与符号的圆润凹边呼应。属于自绘几何字形，不是现成字体，**不可被现成字体直接打出**，具备一定防伪性。

### 为什么不是别的

没有使用：枪械、人物、角色、游戏 Logos、翅膀 / 盾牌 / 皇冠 / 骷髅 / 龙 / 狼；也没有做成典型电竞战队队徽。符号不绑定任何单一游戏，未来扩展到更多游戏时依然成立。

| 近白 | `#F5F6F7` | 245 246 247 | 2 1 1 0 | — | 浅底文字 / 反白 |

金色链与站点现有 CSS 变量（`--xh-accent:#f5b700`、`--xh-accent-strong:#ffc928`）完全一致，替换 Logo 不会带来新的配色分叉。

> CMYK 与 Pantone 为近似值，正式印刷前请以实体色卡对色。

**背景规则**

- 深色底：用 `logo-primary.svg` / `logo-white.svg`（白色标准字）。
- 浅色底：用 `logo-horizontal.svg` / `logo-black.svg`（黑色标准字）。
- 品牌金底：只用**墨黑**单色版本，不要放白色或金色符号。
- 照片 / 复杂底：先加一块墨黑底或使用带底板的图标版本，不要直接压图。

## 4. 安全区域（Clear Space）

最小留白记作 **X**，取符号单个"火花"的宽度。

- 符号四周留白 ≥ **0.5 X**
- 横向 / 堆叠组合四周留白 ≥ **0.5 X**
- 组合内部符号与标准字的间距已锁定，**不要手动改动**

四周范围内不得出现文字、线条、图片、边框或其他 Logo。

---

## 5. 最小尺寸

| 形态 | 屏幕 | 印刷 |
|---|---|---|
| 符号 | ≥ 16 px | ≥ 5 mm |
| 横向组合 | 宽 ≥ 120 px | 宽 ≥ 28 mm |
| 堆叠组合 | 宽 ≥ 88 px | 宽 ≥ 20 mm |

小于上述尺寸时，改用 **只放符号** 的版本，不要缩小组合。

## 6. 禁止使用方式

1. **不要更改颜色**：除规定的金 / 黑 / 白以外，不要换成其他品牌色。
2. **不要低对比使用**：不要把金色符号放在深金 / 土黄底上，也不要把黑色版放在深灰底上。
3. **不要拉伸变形**：只能等比缩放，禁止非等比拉伸、压扁、倾斜。
4. **不要加效果**：不加阴影、发光、描边、浮雕、渐变、贴图、透明叠加。
5. **不要旋转或镜像**：符号保持原始角度。
6. **不要重排组合**：不改变符号与标准字的相对大小、间距和位置。
7. **不要加字或加图**：不在安全区域内添加标语、图案、表情、贴纸。
8. **不要替换字体**：标准字是自绘几何字形，不要用其他字体重排 "XINGHUO"。
9. **不要拆散符号**：不单独取用符号的某一条火花。

## 7. 已知限制 / 待办

- **标准字为描边构建（stroke）**：`logo-horizontal / -primary / -stacked / -black / -white` 中的 "XINGHUO" 使用统一的 20（反白 19）单位描边绘制，已确认无 `vector-effect`、在 viewBox 内等比缩放；正式交付给印刷 / 刺绣 / 切割前，建议在矢量编辑器执行一次 **轮廓化（Outline Stroke）+ 联集（Unite）**，得到纯填充路径。符号本身已是纯填充路径，无需处理。
- **中文标准字未做成字形**：中文名"星火网游"目前沿用站点现有字体渲染。若需要纯字形版本，需选定可商用中文字体并授权后转曲，本包不含中文转曲字标。
- **商标检索**：无法提供法律层面的商标近似判断。正式对外使用前，请到商标局 / 版权与商标数据库做近似检索，并做一次反向图片检索。

```bash

node tools/render.mjs  in.svg out.png 512 "#ffffff" 0.06
node tools/sheet.mjs   out.png cols tile "#f4f5f7" a.png b.png ...
node tools/size-ladder.mjs out.png "#ffffff" 16,24,32,48,64,128 a.svg b.svg
node tools/shot.mjs    page.html out.png 390 844 full
```
