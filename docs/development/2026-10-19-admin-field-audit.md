## 当前验证

- CRM 与目录补充批次：完整 Maven clean package 950 项，零失败、零错误，217 项 UI 由独立 CI 执行。运营工作台 10 个 Chromium / WebKit 场景、目录 3 个浏览器场景通过。CRM 跟进备注不提交，遗漏时保留历史；目录隐藏版本与列表编码，编辑仍保留原编码和 If-Match。
- 同步前端整合主线后，完整 Maven clean package 达 949 项：失败 0、错误 0，217 项浏览器测试交给独立 CI 任务。集成配置字段随后补充，5 项权限 / 状态 / 真实模板测试通过。
- 本机兼容 macOS 的 Playwright 1.48：核心 8 个场景及渠道 Chromium 通过，渠道 WebKit 的 SPA URL 等待改为读取实际查询参数后重试通过。另增加员工配置和权限编辑的真实模板测试，两个引擎均通过；备注不提交，权限编码仍按原协议提交。项目依赖保持 1.63，最终以 CI 的 Chromium/WebKit 全量结果为准。
- JavaScript 语法、发布状态元数据和搜索索引校验通过。
- 本批没有 Flyway 迁移、生产环境变量或密钥变更，也没有企业微信外部写操作。
