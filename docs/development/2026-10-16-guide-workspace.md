# 新版攻略内容工作台

状态：开发验证中，纳入整体验收与最终统一发布。

新版 `/admin/xingwei/guides` 复用完整攻略编辑器：正文组件、排序、关联服务、案例/FAQ、发布、归档与批量生成保留。新模式仅调用 `/api/admin/xingwei/guides/**`，不借旧后台API绕过星维权限；旧入口默认模式不变。

- content:view 可查看列表和详情；全站写入要求 content:manage 与 ALL 范围，兼容只读操作员不能编辑。前端禁用对应动作，后端再次执行。
- 复用 game_guides 既有 version，GET 返回 ETag，修改与单篇归档需要 If-Match，行锁后核对版本；不新增数据库结构。访问量变化不改变编辑版本，不误报冲突。
- 归档与批量生成仍执行原服务与审计，批量归档为明确确认的全局状态操作，保留内容而非物理删除。新模式批量生成发布前增加明确确认。
- 已保存与列表刷新失败分别反馈；冲突保留表单；保存期间禁用写动作和切换，切换草稿有未保存提示。
- 受保护的 `/admin/xingwei/guides/{id}/preview` 可预览未发布稿，使用实际前台模板但不增加公开访问量。预览有 noindex/私有区响应头，不启用评论或收藏写入，不代表已发布。
- 新旧入口共用 GuideContentService，没有第二份内容模型，不改旧后台认证或原接口行为。

测试覆盖只读/全局写入、旧版本拒绝、返回新版本和访问量不造成编辑冲突；Chromium/WebKit 实际模板检查 API 隔离、CSRF/版本头、冲突草稿、只读预览与手机布局。最终以全量构建和 CI 结果为准。
