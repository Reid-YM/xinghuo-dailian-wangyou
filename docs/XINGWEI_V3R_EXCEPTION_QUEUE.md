# V3R 异常订单队列

新版业务工作台增加“异常订单”页签，调用 `GET /api/admin/xingwei/business/orders/exceptions`。接口沿用 `order:view` 和 ALL / DEPARTMENT / SELF 数据范围，数据库先同时过滤归属与 `EXCEPTION` 状态，再按更新时间倒序取最近 100 条。普通订单接口保持原行为。

页签沿用订单表格、搜索和归属调整能力；能否调整归属仍由后端现有 `order:assign` 与数据范围检查决定。没有 `order:view` 的账号看不到页签，也无法调用接口。此阶段不改变履约状态、不新增退款或支付操作、不启用真实收款。

验收重点：有权限的账号只看到自身数据范围内的异常单；旧异常单不会因普通订单最近 100 条上限而消失；只读账号没有归属调整按钮；电脑和手机端可查找业务编号与客户问题；V3H 小程序支付与企业微信写入仍独立验收。
