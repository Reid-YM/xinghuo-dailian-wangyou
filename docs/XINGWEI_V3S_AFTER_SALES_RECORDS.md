# V3S 售后问题记录

客户从订单详情提交售后说明后，内容追加到该订单的客户备注。新版业务工作台增加“售后问题记录”页签，调用 `GET /api/admin/xingwei/business/orders/after-sales`，集中查看带有售后提交标记的订单及其客户说明。

接口沿用 `order:view` 和 ALL / DEPARTMENT / SELF 数据范围；数据库先筛选归属及备注标记，再按更新时间倒序返回最近 100 条。页签内的搜索只筛选本次已返回的记录。无 `order:view` 权限时隐藏页签，直接调用接口也会被拒绝。归属调整继续由 `order:assign` 和原有数据范围守卫决定。

这是一组订单备注记录，没有独立工单状态或退款流程。客户备注中的标记是自由文本，若其他备注中出现同样文字，也可能进入该列表；因此页面不将记录称作“待处理”或“已核实”。客服须结合订单详情核对。此阶段不改变支付、退款、订单履约状态或企业微信写入能力。

验收：不同数据范围的客服只看到对应订单；筛选在 `LIMIT 100` 之前执行；客户备注以纯文本显示；只读客服可以查看但无法调整归属；手机表格可横向滚动。客户侧同一订单提交后的回显由独立前端阶段验证。
