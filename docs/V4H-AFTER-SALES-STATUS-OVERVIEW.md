# V4H 售后处理状态概览

后台售后工作台在 V4G 的记录总数和待跟进客户补充数之外，增加待处理、处理中、已解决三项计数。所有数字来自同一条受 `order:view` 与 ALL / DEPARTMENT / SELF 范围约束的售后记录集合；没有单独处理状态行的记录按待处理计算。数字不受当前队列筛选和分页影响。

点击状态数字会设置处理状态筛选并重置到第一页，沿用现有可分享网址和浏览器返回恢复。其他筛选条件保留，读取失败时不显示虚构数字。本阶段没有数据库迁移或生产配置，也不自动改变售后、订单、退款、真实收款或企业微信写入状态。

后端 PR #465、后台页面 PR #466 和统一版本 PR #468 均通过 Java/Maven 与 Chromium/WebKit CI 并合并。精确主线提交 `d330586c3f391753470725b896dd4c6e8372c7c2` 的双 CI 成功，`deploy/production` 的 `.deploy-request` 指向该提交。Deploy Production #38638784074 完成 18080 候选、8081 金丝雀、8080 正式服务及发布后核验；Nginx 最终指向 8080，上一版 JAR 保留用于回滚。

当前稳定状态变更只同步版本声明与更新记录；它自身仍须经 PR 和主线双 CI，再按同一生产门禁发布。真实售后数据的授权页面操作需要登录后另行核对。
