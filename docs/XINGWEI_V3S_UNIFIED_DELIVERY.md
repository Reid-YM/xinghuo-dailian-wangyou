# V3S 统一交付与验收

V3S 整合两个已分别通过 Java/Maven 与 Chromium/WebKit CI 的阶段：客户订单详情展示已提交售后说明并在提交后刷新回显；新版后台增加按 `order:view` 及 ALL / DEPARTMENT / SELF 数据范围筛选的售后问题记录页签。后台在数据库过滤后按更新时间截取最近 100 条，客户备注只作为文本显示。

交付顺序：功能 PR #409、#410 合入 `main`；本统一版本 PR 经 Java/Maven、Chromium/WebKit、版本状态巡检通过后合入；等待主线 CI 双绿，再由 `deploy/production` 上仅修改 `.deploy-request` 的提交触发零停机发布。发布门禁继续检查 18080 候选、8081 当前、8080 入口与发布后公开/后台边界。门禁完成后另行把 V3S 更新记录由“待发布”改为“已上线”，经 PR 和同一路径发布状态修正。

验收边界：不同账号只看到自身有权访问的订单；客户重新打开详情仍能看到说明；新提交可即时回显；客服列表与详情的用户文本不能执行 HTML；只读客服不能调整归属。售后备注没有工单状态，自由文本中的同样标记可能进入列表，需要人工核对。此阶段不改变履约、退款或支付状态；V3H PR #384 小程序支付保持未合并、真实收款关闭，PR #372 企业微信写入保持独立。小程序正式发布与双设备测试待备案后继续。
