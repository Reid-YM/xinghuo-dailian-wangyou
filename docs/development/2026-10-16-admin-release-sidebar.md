# 后台版本与交付信息收纳

## 行为与范围

工作台顶部不再展示版本号，首页底部不再展开迁移与交付长列表。侧边栏新增默认折叠的“版本与交付”，展开可查看当前版本、运行核对时间，并进入既有 `/admin/xingwei/releases` 专页查看完整迁移历史与更新记录。历史信息提取为 Thymeleaf 片段，保留可追溯性。

正常服务徽标显示“服务正常 · 已核对”；版本漂移、连接失败和超时仍有提示。版本与阶段仍与后端健康接口核对，不以隐藏展示替代运行核验。手机上版本漂移提示继续可见。

## 界面取舍

主工作区聚焦日常业务，版本细节按需查看。沿用黑金导航与原生 details 折叠控件，不引入新组件库、样式文件或额外客户端状态。桌面和手机均默认折叠，手机导航可滚动以访问展开后的链接和退出入口。

不修改接口、角色、数据范围、数据库或生产配置。正式前端继续默认旧版，Next 仅保留显式预览。
