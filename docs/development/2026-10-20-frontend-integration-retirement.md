# 2026-10-20 新版联调与旧版退役

## 本批行为

- 公共前台默认新版；`?legacy=1` 不再选择旧模板，`/next/*?legacy=1` 也不再跳回旧版。账号认证仍在页面替换之前执行，后台原有权限和数据范围继续生效。
- 新版公共导航及浏览器图标使用旧版品牌素材 `/assets/brand-logo.svg`；后台已经使用同一素材。没有重新绘制或生成 Logo。
- 规则、隐私的中英正文从 `/api/public/legal/{document}` 读取。仅允许四个文档名，直接渲染现有模板的 `main`，无旧版页头、导航或脚本；不复制法律文案。响应禁止缓存和索引。原有 `/api/public/**` 公开读取边界覆盖该接口。
- 删除公共页面的旧版链接目标和旧版回退文案；后台服务入口页不再提供旧版预览。`servicesEntryMode=legacy` 的现有配置协议仍表示默认 `/services` 地址，该地址现在同样渲染新版，并不恢复旧界面。
- 首页、服务筛选、询价、账号布局允许网格收缩、长文本换行和按钮折行；输入框与选择框的文字在原控件内显示。Safari 原生控件长值可能将祖先的滚动区域撑宽，明确约束控件溢出。订单表格保留局部横向滚动。

## 联调与验证边界

真实密码/会话浏览器回归覆盖登录失败、登录成功、HttpOnly Cookie、刷新、退出和会话撤销。游客询价、业务进度、账号深链、游戏/服务导航、规则隐私、后台权限等复用现有联调场景；数据仓储和外部服务使用隔离测试边界，没有在生产新建订单、支付或修改员工。

新增测试实际使用 Thymeleaf 渲染四份正文，验证内容及旧壳隔离、未知文档 404。新增窄屏测试在 Chromium / WebKit 的 320、390、768、1440 像素窗口注入长服务名称、长表单值、长品牌名称和账号表格，校验页面宽度与局部滚动、Logo 图片加载及尺寸。

本机 macOS 13 无法运行项目的 Playwright 1.63 浏览器，局部 UI 验证使用缓存的 1.48；正式 CI 仍使用项目原定的 1.63 Chromium / WebKit，不降低项目依赖。

## 发布及回退

用户本次明确要求“正式下线旧版”，公共旧版访问通道按此退役；保留服务器配置 `FRONTEND_NEXT_DEFAULT_ENABLED=false` 作为运维应急回退，未提供公共切换入口。没有数据库迁移、密钥修改或生产权限扩张。

发布前同时记录当前默认前端模式及 `/?legacy=1` 的实际模式。候选检查要求默认及旧版参数入口均为 Next；如果回退上一 JAR，使用上一版本的两种实际模式验证。上一版本尚无独立正文接口和品牌标记时，不能以本批新要求误判回退失败。

最终构建、PR、CI、部署和公网核验以本次交付记录为准；本文件中的代码说明本身不构成上线证明。
