# 新版前后台内部字段收口

## 结果与边界

- 组织表格移除独立中心编号、岗位编码列；数据范围提示不拼接中心编码。正式中心、岗位名称及员工业务编号保留。筛选器与员工编辑器仍提交原编码。
- 权限编辑器按中文业务模块分组；未识别分组使用“其他权限”，不展示模块编码。权限值和服务端鉴权不变。
- 审计摘要改为业务字段白名单，新增或未知技术字段默认不进入响应；浏览器也过滤未知字段、数据库标识和版本。原始审计 JSON 不修改，状态、进度等安全摘要仍可用。搜索不再匹配内部请求编号，保留操作人和业务对象定位。
- 会员活动列表不再返回无后续用途的日志 ID；已删除会员的说明不拼接数据库用户 ID，仍保留公开会员编号、操作、时间和脱敏网络信息。
- 运营列表缺少标题时使用业务类别，不拼接数据库 ID；详情中的对象值不再直接 JSON.stringify，避免已知展示字段携带嵌套内部属性时漏出。普通正文正常展示。
- 个人中心将收藏类型改为中文，显示收藏时间；工具存档隐藏技术键。取消收藏和打开内容仍使用原目标值。
- 失效服务链接提示不回显服务标识；登录设备说明改成直接的设备管理指引。

本批无数据库迁移、环境变量、密钥、RBAC 或数据范围变更。不删除历史备注、审计或协议字段。字段收口针对上述已核查路径，不宣称所有外部支付和员工登录已完成验收。

## 验证

- 审计服务 H2 及 JSON 边界验证：未知及 snake_case 技术字段不输出，原始 JSON 留存，已移除会员不泄漏数据库身份。
- Chromium / WebKit 验证：收藏跳转、取消收藏原协议、分页回退；审计过滤、错误恢复；组织列和权限中文分组、员工配置；运营正文、嵌套内容防泄漏与写入冲突。失效服务文案通过现有契约检查；窄屏沿用上一批布局修复。
- 两组针对性回归共 46 项通过（含本机兼容 Playwright 1.48 的浏览器验证）；完整 Maven clean package 共 980 项，零失败、零错误，226 项 UI 在独立浏览器任务执行。项目依赖仍为 1.63，以 CI 全量 Chromium / WebKit 为准。
- 搜索索引仍为 400 项，校验通过；原编码仍可用于合法筛选和元数据定位。
