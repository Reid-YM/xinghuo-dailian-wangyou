# 新版操作审计工作台

状态：开发验证中；按整体验收计划积累主线，整体完成后统一部署。

旧后台只返回最近100条审计记录。新版 `/admin/xingwei/audits` 与 `/api/admin/xingwei/audits` 在复用现有 audit_logs 的同时，增加按操作类型、操作人/对象/请求编号、北京时间日期范围的筛选、计数和每页50条分页；查询条件可分享并支持前进后退。

- 页面与接口执行 audit:view；ALL 可见全部，DEPARTMENT 按当前操作人所属中心及本人过滤，无中心回退本人，SELF 只见本人。详情应用完全相同的范围。
- 列表返回审计元信息，不返回原始 before_json/after_json、IP、客户端凭据或完整客户资料。
- 详情只返回变更字段摘要；仅对少数明确安全的状态枚举、布尔标记和内部版本/负责人编号显示值，其余内容统一隐藏，嵌套结构、数组和解析失败内容也不直接暴露。
- 没有删除、重写或补记审计的写接口；旧日志与旧后台行为保留。无数据库迁移，无配置、认证或生产变更。
- 复用已有紧凑列表样式，首屏主任务是定位记录；手机筛选换行、任务单列、详情使用键盘可关闭对话框。覆盖空、错误重试、详情失败、长内容、权限不足、安全文本插入。

测试：H2 验证范围、权限、日期时区、字面通配符、分页、敏感内容隐藏；Spring 方法安全代理验证页面和详情无权限时不能执行。Chromium/WebKit 验证实际模板的筛选、分页、详情、重试和手机布局。浏览器实际结果以 Linux CI 为准。
