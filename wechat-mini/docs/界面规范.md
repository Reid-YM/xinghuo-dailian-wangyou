# 星火迷彩小程序界面规范

本规范记录当前页面采用的视觉和交互基线，便于后续新增页面沿用同一套样式。代码以 `miniprogram/app.wxss` 为公共样式入口，页面专属样式写在对应 `.wxss`。

## 视觉基线

| 用途 | 当前值 | 使用方式 |
| --- | --- | --- |
| 页面背景 | `#101319` | 全局底色 |
| 卡片表面 | `#1a1e25` | 普通信息卡、空状态 |
| 边框 | `#2b313a` | 卡片与列表边界 |
| 主文字 | `#e9ecf1` | 标题和关键数据 |
| 次文字 | `#98a1af` | 说明和元信息 |
| 品牌强调 | `#c6f24e` | 选中、进度条、主要操作 |
| 危险操作 | `#e9a0a0` / `#f87171` | 清空等不可轻易撤销的操作 |

- 页面左右留白 28rpx；普通卡片内边距 28rpx；卡片间距 18rpx。
- 页面主标题 42rpx，模块标题 26rpx，正文通常 24–28rpx，辅助信息不小于 20rpx。
- 普通按钮高度约 80rpx；连续设置操作使用列表行，不堆叠大按钮。
- 进度和业务状态必须同时提供文字与颜色，避免只凭颜色判断。
- 提示按“发生了什么 → 现在显示什么 → 能做什么”书写，避免内部术语和未经证实的承诺。

## 页面职责

- **迷彩进度**：记录与查看；首屏突出总进度和模式，筛选与武器列表紧随其后。
- **攻略**：发现与阅读；搜索无结果时提供清除入口。
- **查单**：输入、查询、结果或错误；加载中阻止同单号重复提交。
- **我的**：账户、同步、数据管理、帮助与关于；危险操作置于普通操作之后。

## 必验状态

每页检查正常、加载、空、失败、离线状态；账户页另查未登录、登录中、同步中和同步失败。视觉验收至少覆盖窄屏、大字体、长中文标题/昵称以及网络图片失败场景。

本规范只定义产品的专业呈现，不表示游戏或平台官方身份。
