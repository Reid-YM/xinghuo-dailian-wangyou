# 星火网游 Logo 资产包 · v2

**方案：折光火花 Fold Light Spark（主方案）+ XH 合体字标（备用方案）**

> v2 相对 v1 的变化：符号从"单色火花"升级为"折面火花"——中心用两条轴切出四个折面，光从右上落下，四个面给出四个色阶，像被切割过的金属而不是贴上去的渐变；标准字重新校准了字高与笔画（字高 100 / 笔画 18，反白 17），并把 X、N 的端点从"斜切出头"改回与字高对齐。v1 的纯单色火花保留为**基础标志**（`logo-icon-flat.svg` 与各单色版本）。

> 说明：本次只交付设计资产与预览页，**没有修改线上站点、没有替换现有 favicon、没有部署生产**。文末给出"网站替换位置清单"作为后续建议。

## 1. 创意说明

### 符号：折光火花

四个对角方向的花火，四条边向内收束，中心用水平轴与垂直轴切成四个折面：

- **四点对角 ＝ 星火**：火花／星点的直接识别；
- **对角结构 ＝ 字母 X**：四点连起来正好是品牌首字母 X，一形两义；
- **凹边内收 ＝ 能量汇聚**：区别于普通四角星（忍者镖／罗盘），凹边让形"发光"而不是"锋利"；
- **四个折面 ＝ 高级感来源**：同一色相的四级明度，右上最亮、左下最深，形成唯一光源。这是设计过的折面，不是渐变——没有渐变也会成立。

### 标准字：XINGHUO

自绘几何无衬线大写：字高 100、笔画 18（反白版 17），统一圆角接头；`G` 与 `O` 使用同心圆弧。属于手绘构建的字形，**不可被现成字体直接打出**，具备一定防伪性。

### 为什么不是别的

没有使用枪械、人物、角色、现有游戏 Logo，也没有翅膀／盾牌／皇冠／骷髅／龙／狼；没有做成典型电竞战队队徽。符号不绑定任何单一游戏，未来扩展更多游戏时依然成立。

## 4. 安全区域（Clear Space）

最小留白记作 **X**，取符号单个"火花的半宽"。

- 符号四周留白 ≥ **0.5 X**
- 横向 / 堆叠组合四周留白 ≥ **0.5 X**
- 组合内部符号与标准字的间距已锁定，**不要手动改动**

四周范围内不得出现文字、线条、图片、边框或其他 Logo。

## 6. 禁止使用方式

1. **不要更改折面色**：四个折面只能用规定的四个金；单色版只能用金 / 墨黑 / 纯白。
2. **不要加渐变**：折面本身就是设计好的明暗关系，不需要再加渐变、发光或高光。
3. **不要低对比使用**：不要把金色符号放在深金 / 土黄底上，也不要把黑色版放在深灰底上。
4. **不要拉伸变形**：只能等比缩放，禁止非等比拉伸、压扁、倾斜。
5. **不要加效果**：不加阴影、描边、浮雕、贴图、透明叠加。
6. **不要旋转或镜像**：符号保持原始角度。
7. **不要重排组合**：不改变符号与标准字的相对大小、间距和位置。
8. **不要加字或加图**：不在安全区域内添加标语、图案、表情、贴纸。
9. **不要替换字体**：标准字是自绘几何字形，不要用其他字体重排 `XINGHUO`。
10. **不要拆散符号**：不单独取用符号的某一条火花或某一个折面。

## 7. 已知限制 / 待办

- **标准字为描边构建（stroke）**：`logo-horizontal / -primary / -stacked / -black / -white` 中的 `XINGHUO` 使用统一的 18（反白 17）单位描边绘制，已确认无 `vector-effect`、在 viewBox 内等比缩放；正式交付印刷 / 刺绣 / 切割前，建议在矢量编辑器执行一次 **轮廓化（Outline Stroke）+ 联集（Unite）**，得到纯填充路径。符号本身已是纯填充路径（折面版为 1 条底路径 + 4 个折面），无需处理。
- **折面版的四色印刷**：折面版是 4 个平涂金 + 1 个底色，转 CMYK 时请确认四个金仍能区分；如需极简，可直接用单色版。
- **中文标准字未做成字形**：中文名"星火网游"目前沿用站点现有字体渲染。若要纯字形版本，需选定可商用中文字体并授权后转曲，本包不含中文转曲字标。
- **商标检索**：无法提供法律层面的商标近似判断。正式对外使用前，请到商标局 / 商标数据库做近似检索，并做一次反向图片检索。

## 10. 风格选项与货架测试（追加）

除主方案外，另做了两套**风格明显不同**的候选，并全部放进"和大公司同尺寸对比"的货架测试里。

| 风格 | 构图逻辑 | 适合场景 | 主要风险 |
|---|---|---|---|
| **A 折光火花**（当前主方案） | 单条闭合路径 + 四折面 | 全部场景；小尺寸用单色版 | 单色剪影属于常见"四角火花"家族，差异只在折面 |
| **B 字标主导 + 印记** | 金色印记 + 更轻更宽的 `XINGHUO` 字标 | 超大字号、周边、视频角标；印记做 APP 图标 | 字标主体在小空间退化为印记，需要两套资产 |
| **C 模块化四单元** | 四个相同锥形单元 + 中心菱形，一形四色 | 图形系统、动效、活动换色 | 单元之间有间隙，16px 会并成一团，需另做无间隙小尺寸版 |

文件：`logo/styles/style-b-*.svg`、`logo/styles/style-c-*.svg`。

### 货架测试

把三个候选与 Spotify / YouTube / Discord / Reddit / Telegram / WhatsApp / Vercel / Framer / Figma / Dropbox / Slack / OpenAI / Steam / Twitch / TikTok / GitHub / Apple 放在同一尺寸、同一底色下对比，并额外做了一行**纯剪影对比**（把每个标志压成纯黑，只比形状）。结果见 `explorations/08-shelf-test.png`。

**三条结论**

1. **底板路线只在"底板里是无歧义图形"时成立。** Spotify 的声波、YouTube 的播放键、Telegram 的纸飞机都成立；而**把字母 X 放进方底会被读成"关闭 / 取消 / 错误"**——这是系统级既有语义，品牌改不动。本次实测否决的三个 X + 底板方案见 `explorations/09-style-candidates.png`。
2. **单色剪影比不出高低。** A 的剪影落在常见"四角火花"家族里，靠剪影赢不了 Vercel 三角、Figma 五块那种独特性；差异必须放在"面"（折面）上。
3. **最像大公司做法的是模块化。** Figma（五块）、Dropbox（四个菱形）、Slack（四根条）都是"相同单元 + 系统组合"，在剪影行里辨识度最高 —— 这是 Style C 的依据。

**建议**：主方案维持 A（小尺寸最强、资产最省）；若要更强的"系统感"，用 C 的四个单元做辅助图形与动效，用 B 的轻字标做超大字号场景，三者共用同一条金色链。
