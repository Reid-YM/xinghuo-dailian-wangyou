# V3T 统一交付与验收

V3T 接续已上线的 V3S，将后台售后问题记录从“最近 100 条内筛选”改为按 `order:view` 与 ALL / DEPARTMENT / SELF 数据范围在数据库检索，再计算匹配总数并按更新时间与订单 ID 倒序翻页，每页 50 条。支持业务编号、订单号和客户说明检索；客户说明继续按纯文本显示。功能 PR #415 已通过 Java/Maven 和 Chromium/WebKit CI。

统一版本 PR 更新控制台版本与阶段、业务工作台资源版本、Release History、首页模块说明和状态契约测试。功能不新增迁移，不改变订单、退款、支付或企业微信写入。V3H 小程序支付 PR #384 仍未合并，网站真实收款仍关闭；企业微信 PR #372 继续独立验收。生产企业微信只读接入的 `WECOM_CORP_ID` 与 `WECOM_APP_SECRET` 须由服务器受保护环境提供，页面“待配置”与代码发布状态分别判断。

发布顺序：统一版本 PR 经 Java/Maven、Chromium/WebKit 和版本状态巡检通过后合入 `main`；主线 CI 双绿后，经 `deploy/production` 上仅修改 `.deploy-request` 的提交触发零停机发布。门禁检查 18080 候选、8081 金丝雀、8080 正式入口与后台/公开边界。完成后以独立状态 PR 将 V3T 从“待发布”改为“已上线”，再次走同一发布路径。旧版本 JAR 可回滚代码与静态资源；无数据库回滚需求。
