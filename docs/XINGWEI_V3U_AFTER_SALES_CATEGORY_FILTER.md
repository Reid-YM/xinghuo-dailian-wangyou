# V3U 售后问题类型筛选

V3T 已让客服按权限范围检索全部售后问题记录并翻页。V3U 在同一页增加问题类型筛选，可与业务编号、订单号或客户说明搜索同时使用；切换类型后从第一页重新读取。

接口 `GET /api/admin/xingwei/business/orders/after-sales` 新增可选 `category` 参数，取值与客户提交售后说明时一致：`DELIVERY`、`CANCELLATION`、`REFUND_REVIEW`、`OTHER`。省略或传空值保持原有全部类型行为；其他值返回 400。服务端将白名单类型对应的售后标记与 `order:view`、ALL / DEPARTMENT / SELF 数据范围、关键词一起放入数据库计数和分页查询，客户端不依赖已加载记录做类型筛选。

记录仍保存在订单客户备注中，因此自由文本误含售后标记的问题仍存在。此阶段没有新增工单状态、数据库迁移或退款动作，也不改变订单、支付和企业微信写入。V3H 小程序支付 PR #384 与企业微信写入 PR #372 继续独立验收。

验收包括：部门范围和问题类型在计数与分页前应用；类型与关键词组合；无效类型被拒绝；类型切换回到第一页；手机宽度下筛选控件和表格可用。回滚沿用上一版服务与静态资源；新参数对旧调用兼容。
