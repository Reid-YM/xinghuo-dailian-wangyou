# N29 · Next 移动端导航和可达性收口（第一阶段）

## 已实现范围
- Next 独立预览壳新增带 `aria-label` 的移动端底部导航，覆盖首页、服务大厅、询价、我的、攻略、MW4 工具站、业务记录及客服入口。
- 保留原顶部桌面导航及完整 legacy 正式网站；屏宽 1000px 以下才显示底部导航，桌面端隐藏。
- 移动底栏独立放在顶部导航以外，避免受顶部导航 transform 约束；滚动发生在底栏内部，不需要横向滚动整页。
- 触控目标最小高度 46px，兼容安全区下边距、键盘可见焦点与“减少动态效果”设置。
- 4 个内部 `data-go` 入口沿用 Next shell 的 History/active 状态；其它入口直接指向显式 `/next/**`，保持路由连续性。
- 只调整 Next 预览 `static/next/index.html`；不修改正式首页、后台、订单、支付和业务 API。

## 验收范围
组合验证目标基线：`main` 提交 `189de5504a9dfb11b378e54d7be71bdb32a2c949`（包含同期订单履约开发）；N29 仅验证兼容，不接管该业务改动。测试若未通过需先处理，未通过前不恢复正式叠加验收结论。

- Playwright Chromium 320 / 390 / 768、WebKit 390 验证移动底栏显现、固定定位、44px 触控高度与视口边界；桌面 1280 验证隐藏。
