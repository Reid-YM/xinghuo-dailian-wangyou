# V3V 售后问题详情查看

V3U 已让客服按权限范围、关键词和问题类型检索售后记录。V3V 在同一列表为每条记录增加“查看说明”，以弹窗完整展示业务编号、订单号、订单状态、更新时间、客户说明和内部备注。长说明保留换行并自动折行；缺失内容显示明确占位。该弹窗仅使用已授权列表返回的数据，不额外读取订单，也不改变任何订单或售后状态。

拥有 `order:view` 且数据范围允许查看该记录的账号可以打开详情；只有原本具有业务分配权限的账号继续看到“调整归属”。页面使用 `textContent` 渲染客户和内部文本，避免把提交内容解释为 HTML。PC 与手机端均可关闭弹窗，操作区不因详情按钮覆盖原有分配能力。

验收：Java/Maven 与 Chromium/WebKit 回归检查详情展示、只读角色可查看但不可分配、恶意标签作为纯文本、手机宽度不溢出。无数据库迁移、无配置变更，微信支付、企业微信写入及自动角色开关保持原有边界。
