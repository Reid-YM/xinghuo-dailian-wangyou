## 本轮发现并处理

- N23–N28 之前借用 N14 本身的 hash，自身更新可能无法清缓存。改为服务器输出各资源 SHA256 清单，动态加载器按各自内容指纹取资源。
- N29 四组和 N30 认证回跳的文件名未匹配 CI `*PlaywrightTest`，浏览器方法在 Java job 跳过、在 UI job 没有被选中。统一命名进入既有实际 UI 任务。
- 投稿延迟草稿保存可能丢最后输入或在清空/提交成功后回写草稿；修正离页落盘与清理定时器，账号临时错误支持原位重试，提交期间冻结表单防止成功回调清除新输入。
- 新增完整 MVC 文档 + 全脚本的手机/桌面双引擎测试，避免单独注入模块掩盖整合问题。
