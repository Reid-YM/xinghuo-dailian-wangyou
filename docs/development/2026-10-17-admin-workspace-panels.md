# 后台右侧按菜单显示独立工作区

基线：PR #517 已由生产发布 #223（主线 `591163e2`）于 2026-10-17 00:29:46 完成。18080/8081/8080 完整冒烟、公网 16 项资源哈希、6 个正式旧前端页面和 9 项认证检查通过。随后按用户要求开发本次布局；本次合并不等于自动部署。

## 交互

- 左侧“运营总览、业务中台、组织与权限、渠道与微信、系统工具”分别显示对应右侧工作区，其他工作区隐藏，不再拼成同一长页面。
- 总览保留简短工作台说明、全局搜索和四个工作区入口；入口可用模块数来自现有权限过滤，不增加第二套业务数据。
- 搜索跨工作区展示有权限的匹配模块；暂不显示组织数据表格。清除搜索恢复当前工作区，选择菜单或组织锚点会退出搜索。
- 普通菜单切换从右侧顶部开始，完整显示搜索栏；岗位、员工和角色等深层锚点仍按目标定位。
- 当前工作区标题、页面标题、左侧选中状态同步。保留 hash 地址、直接进入、刷新和浏览器前进后退；`#org-console`、`#org-positions`、`#org-employees`、`#org-roles` 映射到组织工作区，保留定位。
- 无可用模块与无搜索结果分别提示，权限加载期间不先展示未核验模块。客户端隐藏只做导航便利，服务端权限与数据范围仍为真实边界。
- 手机菜单选择后关闭；版本与交付继续在侧边栏默认折叠，版本漂移与健康检查保持。

## UI 取舍

Visual thesis：围绕员工当前选择的工作区组织右侧内容，减少跨功能混排与长滚动。
Signature device：左侧黄色选中项与右侧中文标题一一对应。
Aesthetic risk：总览不铺开全部模块，将功能入口交给明确的工作区导航。
Rejected generic choice：不增加装饰指标卡、补丁 CSS、iframe 或第二套页面数据。
Density / motion：紧凑分区，沿用原手机菜单过渡与减少动效偏好，无新动效。
Intentional tradeoff：保留原模块 DOM、权限映射和组织编辑器，用已有页面所有者管理显示，降低功能迁移回归风险。
Responsive checks：手机 390px、常规桌面 1440px 与宽屏 1920px，检查菜单关闭、分区可见性及无横向溢出。
States checked：权限读取、可用/无权限工作区、搜索有结果/无结果/清除、直接组织锚点、刷新、历史导航、运行版本核对。
Functional validation：保留 26 项模块、角色数据范围、组织配置对话框及原有版本侧栏回归；最终 Java、双浏览器和 CI 结果独立归档。
