# 目录完整资料编辑连续性

基线：PR #516 已由 Deploy Production #222（主线 `6937ea49`）于 2026-10-17 00:02 完成。18080/8081/8080 门禁及公网 14 项资源哈希、6 个旧版正式前端页面、9 项认证检查均通过。以下为部署后的独立下一阶段，代码合并不代表再次部署。

## 行为

- 服务、游戏、图片与批量编辑窗口关闭、Escape 和离页前检查未保存修改；包括下拉、复选框、多选平台和已选择但未上传的文件。取消放弃可继续编辑，确认放弃后清空窗口。
- 选择文件但未上传时，保存前明确确认该文件不会包含在本次保存中。上传成功仍需保存资料引用，关闭前继续保护这些改动。
- 上传、保存和批量影响预览期间显示等待状态、锁定字段和关闭；重复提交不产生第二次写请求。元数据请求 8 秒超时，图片上传预留 60 秒，超时不推断服务端回滚。
- 写入连接中断、超时或无法解析成功响应时，保留输入并提示结果尚未确认；禁止在当前窗口重复提交，清除旧列表操作入口，关闭后重新读取核对。
- 列表读取先清空旧记录和选择；失败不留下旧编辑入口，支持重新读取。过期的成功、失败和收尾均不覆盖后续读取。
- 区分“保存失败”与“已保存但刷新失败”，后者可重新读取验证结果，不重复写入。
- 编辑窗口保存使用打开时的资料类型；仍使用现有 CSRF、If-Match 修订号、影响令牌和服务端权限校验。

## 范围与界面

唯一所有者为 `admin-xingwei-catalog-details.js`，样式在其已有 CSS 内增加禁用态可见性。沿用紧凑资料表单及中文状态反馈；手机编辑窗口可滚动到保存与关闭，不增加卡片、补丁层或额外动画。测试检查桌面与手机的操作状态、无横向溢出。现有分类、批量影响和只读流程保留。

不修改服务端 API、数据库、角色、数据范围、发布规则或生产配置；正式前端继续旧版。图片上传本来就会先保存素材，再由资料保存引用，本次不新增素材删除或后台自动清理。
