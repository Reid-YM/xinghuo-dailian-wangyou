# V4E 客户售后补充与员工跟进

客户在自己的订单详情中可选择已有的 V70 售后记录，提交不超过 240 字的补充说明。服务端先校验登录、订单归属和记录所属订单，再写入 V73 独立表；正文不进入审计内容。历史由客户和具备 `order:view` 且在 ALL / DEPARTMENT / SELF 数据范围内的员工读取。页面均按纯文本显示正文。

员工售后队列按记录提交时间与最近客户补充时间中的较晚者排序，并标出最近补充时间；详情列出客户补充历史。员工处理仍须 `order:manage`，沿用预期版本号并发保护。客户补充不会自动重开已解决记录，也不会改订单状态。客服可根据补充内容手动跟进。
