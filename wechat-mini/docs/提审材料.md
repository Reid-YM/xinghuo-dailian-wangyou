## 三、用户隐私保护指引

**入口（2026 年新后台）**：登录 `mp.weixin.qq.com` → 左侧 **设置 / 账号设置** → **服务内容声明** → **用户隐私保护指引** → **去完善 / 更新**。
（旧版后台在「设置 → 基本设置」页面底部；也可以直接在后台顶部搜索框搜「隐私」直达。）

向导里逐项勾选并填写，每项还要填「存储期限」（如：固定 180 天）与「是否提供给第三方：否」：

| 收集的信息 | 用途说明 | 存储方式 |
| --- | --- | --- |
| 用户身份标识（openid） | 保存进度、跨设备同步、区分不同用户 | 微信云开发数据库 |
| 用户操作记录（迷彩进度、收藏） | 保存与恢复用户的进度数据 | 微信云开发数据库 |
| 用户填写的昵称、头像（选填） | 在「我的」页面展示；用户关联网站账号后同步到星火官网账号，使两端显示一致 | 微信云开发 + 星火网站服务器（自有服务器） |
| **手机号（选填）** | 用户在「我的」页主动点击「授权手机号」后获取，保存到其网站账号作为客服回访联系方式；不用于营销，不提供给第三方 | 星火网站服务器（自有服务器） |
| 相册权限 | 用户主动把迷彩大图保存到相册（代码目前只用预览图，长按保存由用户自行操作；可依后台可选项决定是否保留此项） | 不存储 |
| 设备与网络信息 | 展示官网工具站数据时的正常联网请求 | 不存储 |

> **必须填**，不填会被驳回。这是"用了 openid 存进度"的强制要求。
